# DECK ZERO – Freischaltungs-Liste

Diese Liste liest die Tester-Version von DECK ZERO beim Start und alle 10 Minuten.

- `aktiv`: `true` = das Spiel ist spielbar, `false` = für alle gesperrt (Text aus `nachricht` erscheint im Spiel).
- `spieler`: **Prüfsummen** der Schlüssel mit einem Namen. Aus einer Prüfsumme kann man keinen Schlüssel ablesen –
  darum darf diese Liste öffentlich sein. Die Schlüssel selbst stehen **nirgends** hier.

Gepflegt vom DECK-ZERO-Studio auf Tims Wort (Werkzeug `tools/lizenz_liste.py` im Spielprojekt).
